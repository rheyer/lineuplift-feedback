# LineupLift feedback

Something not working as it should? Have an idea that would make
[LineupLift](https://lineuplift.com) more useful? We'd like to hear it.

[Report a bug](https://github.com/rheyer/lineuplift-feedback/issues/new?template=01-bug-report.yml)
· [Suggest an improvement](https://github.com/rheyer/lineuplift-feedback/issues/new?template=02-improvement.yml)
· [Browse feedback](https://github.com/rheyer/lineuplift-feedback/issues)

For a bug, tell us what you were trying to do and what went wrong, even if
it only happened once. For an improvement, tell us what you'd like to change.
A short description in your own words is enough. Screenshots and browser or
device details are welcome if you have them, but aren't required.

We'll read your feedback, look into problems, and ask here if we need more
information. If you're unsure which form to use, pick whichever seems closest.

## Keep private information private

This repository and every issue are public. Please leave out passwords,
ESPN sign-in cookies, private league links or IDs, and manager or team names.
Don't attach league files or full reports. Hide private information in any
screenshots before sharing them.
