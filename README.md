# LineupLift feedback

Report bugs and suggest improvements for [LineupLift](https://lineuplift.com),
the fantasy-football trade analysis app.

[Report a bug](https://github.com/rheyer/lineuplift-feedback/issues/new?template=01-bug-report.yml)
· [Suggest an improvement](https://github.com/rheyer/lineuplift-feedback/issues/new?template=02-improvement.yml)
· [Browse existing feedback](https://github.com/rheyer/lineuplift-feedback/issues)

Before opening an issue, search existing feedback. If someone has already
reported it, add a reaction or useful details to that issue.

For bugs, explain what happened, what you expected, and how to reproduce it.
Include your browser and device when relevant. For improvements, describe the
problem you want to solve and how the change would help.

## Keep private information private

This repository and every issue are public. Do not post ESPN cookies, tokens,
passwords, private league IDs or links, manager or team names, league snapshots,
raw reports, or unredacted screenshots. Use the app's synthetic example to
reproduce a problem when possible. Otherwise, describe it without identifying
your league and redact any screenshots or error text before sharing them.

This repository is the public feedback tracker. It does not contain the app's
source code or league data. Feedback is reviewed here; opening an issue does
not guarantee a particular release date or implementation.
